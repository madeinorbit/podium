Working mark designs

Give each design up to three points with the dots on its card, add a note if you like, then press Export picks and paste the text into the chat. The build buttons draw the marks every way measured, each set up the cheapest way for the browser you're in (named above); Best for this browser is the cheapest overall. Dots moves each dot; GPU flipbook, Stepped flipbook and Sprite step pre-drawn frames; Shared canvas and Worker canvas draw them; APNG is built in the page; WebP, AVIF, GIF, SVG and the videos are files made for the two shortlisted designs at 12 px (elsewhere the APNG stands in, outlined). Own fps runs each design at the lowest frame rate that still moves smoothly at 12 px; Shorter loop runs it faster; Mirror draws half the frames where a design allows it; Pause when idle stops the marks after 5 s without input. Each card shows what the design costs with the build and frame rate you picked: one to five filled bars, fewer is lighter. Crowd is the load test: up to 1000 marks, with a box that shows how fast your typing reaches the screen.

Built for the sizes the app really uses (11–13 px), so each card shows those first; the 56 px copy is for detail. Every design is only round dots, one moving layer per dot, with depth faked by shrinking and fading. There are no 3D transforms, so Safari, the Mac app and Chrome draw them alike. Safari 26 freezes animations that come back from display: none (this page in a hidden app tab counts) or from content-visibility (WebKit bug 301745), so each mark re-syncs itself when it comes back into view. Round 1 is in working-mark-designs.html.

The shortlist at each frame rate, side by side, at 12 px and 32 px. Pick the lowest rate that still looks smooth to you: with the sprite, the animated image and video, a lower rate means fewer redraws a second, so it costs less. The rows below each design run its loop faster and slower. Under each mark: frames per loop (memory), and the furthest a dot jumps or fades between two frames at 12 px. The outlined cell is the design's own rate.
