Two fills, and that is all.A task is grey in every state — working, blocked, done, selected or not. A proposal is fuchsia. So purple in this column means exactly one thing: this task does not exist yet.
Selection and attention are ticks.A 3×18 square standing in the rail's gutter: the mission accent for the strip you are on, amber one notch further out for a strip with a session asking inside it. Neither is ever a fill or an accent border, so the two can stand side by side.
The rail carries the lead.A branch whose owner has a live coordinator draws its guide 2px in the mission accent — full strength for the mission's own lead, 22% for a task's. Only that agent's elbow is drawn in the colour; everyone else on the branch keeps a hairline, so the line names one agent instead of tinting the roster.
Agent rows are contents, not objects.No fill, no outline, no rounded collar — the only rectangles left in the column are tasks. The mission coordinator is the single exception. Even the asking row stays unfilled: amber type, an amber inner rule, the ! disc.
One rail, one indent.A task's agents and its child tasks now hang on the same line at the same indent. The old geometry split them two lines apart so a child could never read as an agent; an agent that is no longer drawn as an object cannot be mistaken for one.
A fold costs no row.The census and the task count moved onto the strip itself — a harness square per session, capped at four with +N, dimmed when settled. The held seat did the same: a dotted chip where a staffed task shows its crew, instead of a presence line underneath.
Proposals sink.They leave the sibling order for a tail under a divider that carries their count, and each names the session that filed it.

The one decision taken here rather than inherited

The root roster fold is gone.

The web removed it on the rule that nothing in the spine is hidden by default and what narrows the column is the view bar. A phone has less room to absorb that, so on a long mission the panel now opens onto every retired agent before the first task. It goes anyway: the deliverable here is that the two decks read the same, and a mission showing sixteen agents at a desk and “12 finished” in a pocket is exactly the divergence this work exists to close. Settled agents dim one tier, which is what keeps the cost visual rather than structural.

Deliberately not carried over

Two web devices stayed behind, both because they are desktop-shaped rather than because they were forgotten.

DeviceWhy not
The rigid 70px state columnIt is a device for a wide list. At 393pt a title, a ref and a state word cannot share one line, so the phone keeps its iOS subtitle row and the title keeps the full measure — the same facts, one line down.
Container-query drop orderReact Native has no container queries. The phone's equivalent is the two-line strip itself: the title truncates, and the chips beside it are flex: none so they drop nothing mid-string.
Three-valued foldsThe web stores open/closed explicitly and defaults a one-agent task to closed. The phone still uses a plain folded set. Behaviour, not appearance — filed rather than smuggled into a visual change.
