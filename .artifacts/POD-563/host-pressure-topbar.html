One chip per machine carrying a single readout, then a hairline, then quota. The instrument well is one object with internal structure — that is the constraint the proposal has to honour.

2 · Proposed — the same chip, three readouts

No new group, no new seam. LOAD and AGT join MEM inside the machine chip, because host pressure is not a peer of host memory — it is host, more of it. Shown here at the POD-526 incident reading: memory fine, machine on fire.

3 · What the meters are scaled against

Load has no natural ceiling, so filling a bar to "100%" would be meaningless. Both new meters fill against the policy threshold that governs them — a full meter means "Podium is parking agents right now", which is the only question the readout has to answer, and it stays honest when a threshold is retuned.

AGT counts residency, not activity — status ∈ {live, starting, reconnecting} on this machine. The status strip already owns "N agents working" and one fact is never stated in two places. Residency vs activity is the POD-526 story: five agents visibly working, thirty-nine resident.

4 · States

At rest, marks and values sit at dim ink and only the meters carry tint. The health dot is the chip's one escalation channel — it takes Superade Yellow only when something is genuinely being asked of the operator, per The Signal Rule.

healthy podium-vps MEM34% LOAD0.4× AGT3
approaching podium-vps MEM48% LOAD1.3× AGT7
parking podium-vps MEM35% LOAD1.8× AGT39
reclaimable podium-vps MEM34% LOAD0.5× AGT3
link down podium-vps MEM34% LOAD— AGT—

reclaimable is the only state where the machine is calm and the dot still lights: 97 stale checkouts are not costing CPU right now, but they are the operator's to release. Link health outranks it when both apply. Stale samples blank the values rather than showing a last-known number.

Why these lines

WorktreesThe headline number. Closed issues whose checkout is still on disk, with no live session in it. Review opens the janitor's candidate list.
Idle sessionsSplits what the policy can park from what it refuses to — needs_user and no-resume-ref sessions are protected on purpose.
HeldThe most important line here. The one class automation will never touch. Without it, an operator has no way to learn that some of that disk is theirs to resolve rather than the janitor's.
GC linkSecond deep-link beside the existing hibernation one, using the same setSettingsTab pattern already in LoadPanel.

Fetch cost

The three bar readouts ride the existing 5-second sample and the client store. The inventory needs a du + git status walk, so it is fetched on panel open only, cached 60s — the same shape as the existing memoryBreakdown daemon RPC. An inventory probe walking 100 worktrees every five seconds would be a small copy of the problem this issue exists to fix.

6 · Narrow behaviour

The bar gives up words before data, and data before controls. The new readouts slot into the existing shed ladder without inventing a rung. A number that has crossed a threshold is never shed.
