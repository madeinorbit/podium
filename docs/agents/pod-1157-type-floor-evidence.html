The one thing the raise put at risk

“Best for multiple computers” is 27 tracked mono characters. At 10.5px it is wide enough to run out of room in a phone-width column, and the chip was a fixed h-[19px] pill — so a second line would have spilled out of it. The pill now grows instead: min-h-[19px] with 2px of vertical padding, which is the exact same 19px whenever the text fits on one line.

This supersedes a landed decision. A second session reached the same red test and answered it the other way: it raised the crash screen summary exactly as here, but sanctioned the three activation chips at 9px, adding SANCTIONED_SUB_FLOOR entries declaring 2 sites in ActivationShell.tsx and 1 in ExistingPodiumActivation.tsx. Raising the chips empties those entries, so both are removed here.

The disagreement is over one word in the exception's own text: it sanctions mono tokens that read “as a mark rather than as prose”. deleted and epic are marks. “Best for multiple computers” is a five-word recommendation set in mono — prose wearing a mark's clothes — and unlike a numeral in a 16px circle or a fixed-width column token, no geometry was holding it at 9px. Neither sub-floor list carries an entry for these files now, and apps/web/src/app/type-floor.test.ts passes.
