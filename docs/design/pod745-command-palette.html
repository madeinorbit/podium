POD-745 · Command palette

The palette is the command bar,
arrived.

⌘K was the one surface in Podium made of nothing from Podium — a stock dialog with a bordered input, 13px rows and a grey wash on the selected one. It also showed eight arbitrary agents and nothing else the moment you opened it, because every kind of result shared a single cap of 8. This rebuilds it out of the shell's own parts and fixes the reason it was hard to use.

01

At rest — ⌘K, nothing typed

The resting palette is a home, not an index. Recent merges agents by last activity and tasks by last touch — the answer to "what was I just doing". Below it, what you can do to the task and the agent the shell is pointed at, then the command list. The raw indexes (every task, every agent, every worktree) are answers to a query and are not offered before there is one.

04

What it is made of

The field is a well

The command bar's signature control at full width. Its floor is --bar, the darkest tier — a groove is a per-ground call, and on --chip, the lightest tier, a recess goes down in tone rather than up the way it does on the near-black bar.

Selection is the raised cell

The same bevel the active mode tab wears, from the same --well-cell-* tokens, so it flips with the ground for free. It replaces a flat bg-accent wash that said "hovered", not "this is what will happen".

One yellow thing

The ↵ cap marks what Enter will do, on the row it will do it to — the Signal Rule's one voice per region. It is laid out on every row and revealed on one, so the hint column never jitters as the highlight walks the list.

Machine voice

Group labels, refs, hints, counts and the footer are Geist Mono at the Label role — the voice the overlay menus and the colour picker already name their regions in. Row titles stay Geist Sans: they are the human's words.

Rows carry identity

Task rows are the canonical IssueReference — stage glyph, ref, title. Agent rows carry the harness mark and the live agent-state glyph, so a working agent spins in the palette exactly as it does in the sidebar.

Motion earns its keep

One authored moment: the panel drops in from 9px above on an exponential ease-out, 170ms. Everything after that is instant. The field's braille spinner runs only while a server search is genuinely in flight — the same predicate the agent spinner gates on.

The footer teaches

The status strip's grammar, borrowed to close the surface. It is also where the ⌘K commands hint that used to sit in the app's own footer all day now lives — stated once, at the only moment it is useful. Escape's label tracks what Escape will actually do next.

05

What it can now reach

The audit found ten action points with no ⌘K route. Six shipped with the redesign; four need a decision or a dialog that does not exist yet.

AddedWhy it mattered
Dock panels ×7Task, Superagent, Git, Files, Shell, Messages, Queues — plus Close side panel. Exactly one of the seven ("the superagent panel") had a route before, under copy that predates the dock.
Go to SpecsA MainView and a top-bar tab. The views array listed six of the seven; this was a plain omission.
Settings · tabEvery settings destination, from the shared SETTINGS_TABS. ⌘K could only land you on the default page.
Add repo…The other half of the two-tool footer row ⌘K search sits in. Every new project goes through it.
Mark agent read / unreadThe shared eligibility helper computes five flags; the palette destructured three.
RecentNot a command — the resting state's whole answer, and the reason ⌘K no longer opens on eight arbitrary agents.
Left outWhat it needs
Rename agentThe context menu's first item. It takes an onRename callback from its host and there is no palette-owned rename dialog to hand it.
Agent handoffWired for tasks, not for the focused agent. Needs the machine-candidate list projected the way the task path already does.
Split / unsplit panetoggleSplit behind the tab-splitting flag — a shell-layout action with no keyboard route at all.
Theme & densityFlipped often, reachable only through Settings. Worth a pair of palette rows; wants a call on whether ⌘K should hold preferences.
