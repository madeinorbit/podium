Prototype The count is the click target — the row toggles the full list either way.

What changes

  • The batch becomes live. Today a run of tool calls only collapses after it finishes; while the agent works the operator watches rows pile up. The work line exists from the first call and mutates in place.
  • The count is the progress. A mono tabular counter ticks per call, so digits never shift width and the row height never moves — the feed below it stays still while the agent churns.
  • Failure never hides. A failed call surfaces on the collapsed line in red with its count, and its error line is pinned inside the expanded list.
  • One block, one tick. The whole run is a single minimap tick, so a 40-call turn reads as one beat of activity instead of forty.

How it obeys the system

  • Carved, not floating. The row is engraved into the field with an inset shadow and hairline seams; the deck behind it is two same-tone tiers, not a drop shadow.
  • Machine voice stays mono. Tool, target, magnitude, duration and the counter are Geist Mono; the summary phrase, addressed to the operator, is Geist Sans.
  • Motion means state. The braille spinner and counting timer run only while the agent computes; each new call is one 200 ms morph, then stillness. Reduced motion freezes the glyph.
  • Signal stays scarce. Yellow marks the answer keyline, the offer's primary action, and the send key — nothing else. Live activity reads calm blue; the issue tint is a mix, never a fill.

Open questions

  • Threshold. Should a single tool call render bare, as today, with the deck and counter appearing from the second call on? The prototype drops the deck at a count of one.
  • Sticky while working. On a long turn the work line scrolls out of view. Pinning it to the bottom of the feed while live would keep progress on screen — at the cost of a second sticky element beside the operator prompt.
  • Verbosity setting. Power users may want the run expanded by default per session; non-technical viewers of a shared session never want it. One toggle, remembered per session.
