## 4. Displayed-fields fence (report-only finding)

`displayed-fields.test.tsx` runs both roster arms. MobX passes. Hand, as `measuredOnly`, REPORTS: `sortKeyOnly (P1): REPORTS [commits] sortKeyOnly (P1): drew 1 rows, the oracle changed 0. over=[i214] under=[] remounted=[] rowsCommitted=1 parity=pass`; the title step passes (changed 1, drew 1). With the flag removed the placement step throws — the recorded red output above. Mechanism: `buildRowView` spreads `...own`, and `own` carries `sortKey`/`repoKey`/`foldAt`, so a placement-only change remakes the row's whole view object and notifies its listener; MobX passes by per-field subscription granularity. The hand rework owns the fix.
