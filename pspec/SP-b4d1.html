Issues carry an optional user-assigned colour, one of 10 predefined palette slots (rose, pink, fuchsia, violet, indigo, blue, cyan, teal, green, lime). Persist/transmit the SLOT NAME (key), not a hex — the palette maps each slot to a full colouring scheme, so schemes can be retuned without touching stored data. Unset = default = neutral grey-black/slate rendering. Assignment is manual via the colour-picker popover opened from the issue's ID square; palette-only in the UI (no freeform hex). Amber/orange, Claude terracotta, and working-green are reserved for status and never pickable. (Till, 2026-07-14)
