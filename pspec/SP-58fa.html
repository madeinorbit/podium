Harness executable environment

The daemon owns one immutable, generation-tagged command environment. It recovers PATH only for PODIUM_DESKTOP_SUPERVISED=1, resolves and verifies each harness once, and reuses that exact absolute executable and PATH for inventory, login, interactive, exec, headless, model, and quota operations.

@podium/runtime owns OS command recovery, @podium/harness owns declarations and commandless invocations, and adapters retain only provider arguments and credential rules. Machine binary home and credential home stay separate. Refresh atomically replaces generations and stale inventory completions are discarded.

Acceptance combines hermetic race and boundary tests, an opt-in two-shell Linux Docker smoke, and one manual Finder/Homebrew check on macOS.
