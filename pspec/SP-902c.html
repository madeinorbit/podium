Phone user agents visiting / get the main web app's responsive MobileApp shell (the <=768px shell), NOT a redirect to the Expo mobile web build. The Expo app remains reachable explicitly at /mobile; when the Expo build is absent, /mobile redirects to / rather than falling into the main SPA. All mobile-entry redirects (/desktop, /mobile fallback) preserve the query string (?server, ?e2e). The podium_desktop opt-out cookie is retired. Decided during the #45 mobile-shell redesign acceptance (2026-07-14); implemented in #58 (registerMobileRouting in apps/server/src/static-web.ts).

Long-term direction (human decision, 2026-07-14): this default is interim. The Expo app (apps/mobile) is the eventual mobile experience; it is to be redesigned to match the responsive web redesign (tracked as draft issue #60, to be started by the human separately). Flipping the phone-UA default at / from the responsive web shell to Expo is a separate explicit decision to be made once Expo reaches design parity — not implied by this component.
