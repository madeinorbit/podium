Board What changed

  • Fixed card grammar. Ref+avatars / title / one state line that never wraps. The old wrapping badge bag is gone; overflow collapses to +N.
  • No column boxes. Columns are hairline-separated and carved into the chassis, headers on the 36px datum — not floating grey panels.
  • Issue colour on every card via the tint channel, so the board finally uses Podium's signature.
  • Real drag. Lifted proxy, insertion line, gap opens, 180ms settle. Drop target is a tint wash, not a yellow ring.
  • Yellow only where asked. Card hover is a tonal wash; Approve is the one yellow thing in Proposed, and it only appears on hover or selection.
  • Selection is visible. Hover reveals a checkbox where the ref was; the bulk bar rises from the bottom.

Detail What changed

  • The Now block. Live agents, what each is doing, and the branch state — carved, at the top. The page currently shows less than the sidebar row for the same task.
  • Context bar carries live state: needs-you, working count, GitStamp. Breadcrumb shows the real parent chain.
  • Dossier line replaces the chip salad. Ordinary facts are text; only exceptions (agent-created, draft, hub·stale) earn a chip.
  • Activity is readable. Day dividers, relative times, runs of low-value events rolled into one expandable line, comments visually dominant.
  • Composer is pinned, not 6000px down the scroll.
  • Rail ranked and truncated. Status/priority/assignee, then sessions, then branch; empty estimate/due/defer fold under "More fields". Native date inputs are gone.

Not yet in this prototype: keyboard focus ring pass, Daylight variant, list/flat mode, and windowed rendering for the 140-card Proposed column (shown truncated here). Fonts are system stand-ins — the real surfaces use Geist and Geist Mono.
