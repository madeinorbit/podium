Why it went wrong

Two independent faults stacked:

  • The catch-all lied. Every unmatched path returned index.html with 200, so an icon probe, a crawler and a link unfurler all got a web page where they asked for a file. iOS probes /apple-touch-icon.png and /apple-touch-icon-precomposed.png at the origin root as its documented fallback; it cannot decode HTML as a PNG, so it kept whatever it already had.
  • The declared icon was the wrong art. The desktop shell's <link rel="apple-touch-icon"> pointed at a lectern glyph only this app still wore — so the fallback path and the declared path both led somewhere wrong.

The catch-all now serves the shell only for navigations. A known asset extension, or an Accept that rules out HTML, gets a real 404. Sec-Fetch-Mode is used when present but never required — it does not ride on plain-http LAN requests, which is how Podium is usually reached.
