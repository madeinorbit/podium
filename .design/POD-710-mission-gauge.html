Mission gauge — three options

POD-710 · GAUGE stream. The bar in the flight deck's mission header. Rendered on the header's real ground (issue tint 18% over the tabstrip tier), at the column's real width, in Superade dark.

  • One unit of work = one task. The root is the container being measured, never a segment. A mission of one task shows one thing, once.
  • Motion is licensed by the predicate, not the device. The sweep runs only while an agent is actually computing — a parked in_progress task leaves it still.
  • Blocked is hueless. --warning IS --attention here; blocked work asks nothing, so it wears the deck's own hatch, not the signal colour.
  • No green. Done takes --success (Accent Blue), running takes --live. Separated by material, not only by hue.
  • Presence stays outside the track. N live is not a segment of the work.
  • It is a meter. Data, not decoration — and it never spends a pixel on itself.

C

The operator picked C, the split readout. Option C above is now the implementation — its CSS in this page's <style> is the block that went into styles.css, and its markup matches MissionGauge.tsx element for element, so what you judge here is what runs.

C's one weakness was crowding, and that is what the build had to answer. The deck column is resizable from 300px (AppShell, default 360, max 620), so a band running out of room is routine rather than an edge case. It sheds the way the command bar sheds — words before data, data before material, nothing ever clipped:

  • Rung 1 — the band fits 4 DONE: count and noun.
  • Rung 2 — the band fits 4: the noun is dropped whole. There is no 4 DON…; a meter that truncates a four-letter word has stopped being data.
  • Rung 3 — narrower than that: bare material. The colour, the hatch and the floor rule still say which state the band is and how much of the mission it holds, by being there.
  • A zero-count band is never drawn at all — not a 1px sliver. That is C's whole premise, and it is decided in the component, not in CSS.
  • The rung is the BAND's width, not the column's. Each band is its own inline-size container, so a wide 6 DONE keeps its noun while the one-task band beside it is already a numeral — the honest reading of who has the room.
  • The full sentence is on the gauge's aria-label and title at every rung, including bare material. The reading never degrades; only its typography does.

Thresholds are the text's own measure — Geist Mono advances 0.6em, so a character at 9px with 0.06em tracking costs ~6px — plus ten of slack, with the count's rung keyed on how many digits it actually has so 128 never lands in a box sized for 4. They are min-width rungs only, so a browser without container queries lands on bare material rather than on clipped text. Try the Deck column control at the top of the page: at 300px the eight-task mission is down to numerals, and at 620px every band has its noun back.

One correction the build also carried: the sweep now gates on working, not on run. The shipped gauge animated on a task-stage fact, so a mission parked in in_progress overnight swept all night — motion outliving the computing it depicts, which DESIGN.md §5 forbids. It is now the same predicate RowProgressMeter uses.
