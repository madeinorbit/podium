Session header — three redesign variants

The agent panel header carries too much at equal weight, encodes the chat/native mode twice in two disconnected places, and mixes four type sizes on mismatched baselines. All three variants fix the same four defects and differ only in how the mode switch is expressed.

Why it works The segmented control is the canonical fix for toggle ambiguity: both states are always visible and labeled, the filled segment is unmistakably "where you are". The git stamp keeps its POD-98 grammar (branch · state dot · counters) and its click-through to the Git panel. Inline actions are now exactly the operator's triage verbs — park it (snooze) or file it (archive) — while transient utilities (take control, resume, ask, hibernate) sit one click away.
Model token — feasibility confirmed. Every Claude assistant transcript record carries message.model, so the server can surface the observed model (resolving spawn-time auto to e.g. "fable 5"). Effort has no runtime source — only the spawn-time requested value exists — so "med" renders from that field and hides when unknown. Small protocol addition: extract message.model in the transcript parser, carry last-seen model on the session snapshot.

B Mode as tabs

Chat and Terminal are two views of one session — the honest affordance is tabs, using the same underline grammar as the app's tab strip. The mode lives where the eyebrow was, so the right side is purely actions, grouped by a divider: frequent inline, rare behind the overflow.

Tradeoffs Two tab rows stack in the panel (session tabs above, mode tabs below) — the hierarchy must stay legible via the size difference. Widest of the three variants; on mobile the tabs collapse to icons.

C Labeled action pill

The conservative fix: keep the single-toggle architecture, but make the button say what it does with a verbless target label — and let hover state carry the rest. The eyebrow dies (the visible pane already tells you the mode); rare actions stay inline but drop to 40% opacity until the header is hovered. Smallest diff from today.

Why it works "Open chat" cannot be misread as a state — the verb makes the icon's target semantics explicit at the cost of ~60px. Every control keeps its current home and muscle memory; the opacity recede restores hierarchy without removing anything. This ships in an afternoon.
Tradeoffs Still seven targets — the recede treats the symptom, not the count. Hover-reveal doesn't exist on touch, so mobile keeps full opacity (where these are already pruned by isMobile). The mode label changes with locale length (i18n width risk on the pill).
