POD-608 · Transcript chat design language · 08 Aug 2026

The transcript is an instrument, not a chat room.

Keep Podium’s density, minimap, tool fold, agent-state motion, mail and offers. Quiet the permanent decoration, make human intent the turn anchor, and let Superade yellow mean exactly one thing: the operator is being asked to act.

Distinctly PodiumQuieter densityYellow = attentionNo inline diffsMinimap stays
Core decision
Keep sticky + clamp.

Cursor, Claude and Codex can leave prompts full-height because they do not pin them over their own feed. Podium’s sticky turn context is useful during long autonomous runs; an unclamped sticky prompt would consume the reading surface. Keep the behavior, reduce it to a two-line context shelf, and keep “Read more” reachable in the fixed label row.

01 · Direction

Three rules organize every state

This is a refinement of the August chat redesign, not a reskin. The feed’s composition is already strong; the remaining work is signal discipline and consistent state semantics.

01

Human intent anchors the turn

The operator prompt is the exchange header. In scroll-back it becomes a compact context shelf; in normal flow it remains a quiet, issue-tinted block. Answers and work bind below it without repeated yellow separators.

02

Machine activity compresses

Tool calls remain one mutable progress object. Working moves in calm blue; shell and subagent waits become still, named dependencies; completed activity recedes into neutral machine voice.

03

Yellow is a request, not décor

Needs-input cards, plan approval, the primary offer action, and a sendable composer may spend yellow. Answer rules, minimap answer bands, idle focus borders, and passive labels may not.

04 · Sticky prompt decision

Keep the context, cap the footprint

The explicit choice is not “truncate user messages.” It is whether an overlay may consume the reading surface. Podium’s clamp exists only because Podium pins the active request.

Reject

Drop sticky

Matches peers, but loses the question while long autonomous work scrolls beneath it. The minimap can navigate back; it cannot keep the current turn legible at a glance.

Reject

Sticky, no clamp

Preserves context until the prompt is long—then it blankets the response it is meant to explain. This fails exactly on detailed agent briefs, where context is most valuable.

Recommend

Sticky + clamp

Keep the shipped behavior with a quieter shape:

  • Two text lines at rest, ≤96px total.
  • “Read more” in the always-visible label row.
  • No gradient fade unless content is truly hidden.
  • Issue-tinted seam, not a yellow active border.
  • Expanded height scrolls internally and collapses in place.

07 · Composer

Remove terminal cosplay from Chat

Native mode already owns the honest terminal. Chat is a structured transcript surface, so its input should read as a compact command bar—not a second pseudo-terminal.

Remove

The “>” glyph

It contributes no affordance, steals the first character’s alignment, and implies shell semantics that do not apply to attachments, voice, issue mentions or queued sends.

Remove

Yellow focus border

Focus is persistent navigation state, not attention. Use the issue-tinted seam plus the platform focus ring. Reserve yellow for a sendable primary action or a waiting-on-you state.

Keep

Floating compact shape

Keep the inset 10px shell and one-line start. Empty send is neutral; a valid send becomes yellow. Attachments and queue/error text occupy stable rows without shifting the field.

08 · Tokens

Colour carries meaning

No new palette. The proposal uses existing Podium tokens more rigorously.

Issue tint

identity · prompt shelf · active pane

Calm blue

working · live timer · active computation

Superade yellow

operator action · needs input · primary offer

Alert red

error · destructive action · never ordinary stop
09 · Component map

Where the language lands

Design-only scope. These are the existing owners that would implement the language; no parser work or inline diff surface is implied.

ChatBlockView · TranscriptFeed

Context shelf, prompt/answer hierarchy, interruption composition, turn spacing.

ToolBatchView · ToolBlock

Named dependency states, stable collapse/expand grammar, failed-tool + interrupt grouping.

TranscriptTail

Working moves in blue; shell/subagent waits are still and named; needs-input hands attention to its card.

ChatComposer · AttachmentStrip

Remove “>” and yellow focus edge; neutral empty send, yellow actionable send; stable queued/error/attachment rows.

AskUserQuestionCard · OfferBar

Only one yellow primary per attention card; secondary decisions remain neutral and carved.

Minimap · ChatRail

Keep geometry, scrub, search marks and legend. Replace passive yellow answer bands with the neutral/issue ramp.

MachineContextRow · mail envelopes

Machine voice stays mono, collapsed by default, with provenance and timestamp in one quiet header.

ChatView

No new header. Search stays behind ⌘F; the rail remains the permanent reading instrument.
